# 提供初始店家名單

可直接在對話貼文字，每間一段。不確定的欄位填「未知」，不要推測。

```text
店名：
Google Maps 分享網址：
地址：
座標：緯度、經度（可先不填，新增地圖前需確認）
電話：
營業時間：例如週一～週五 11:00–14:00、17:00–20:00；週六日休息
餐點類別（可複選）：早餐／早午餐、便當、牛肉麵、拉麵、其他麵食、牛排、火鍋、咖哩、義大利麵、小吃、輕食、咖啡／甜點、冰品；用頓號分隔，未知留空
葷素：葷食／素食／葷素皆有／未知
每人預算：約 NT$ ___
避雨路線出發點：名稱與座標
從上述出發點走過去全程可避雨：是／否／未知
```

- 可以先給店名＋Google Maps 網址建立待整理清單；網址不是自動匯入 API，也不能保證只靠網址取得電話或營業時間。
- 真正新增店家需要店名與確認的位置。電話、地址、預算、營業時間與避雨標記可未知。
- 營業時間請列出休息日與午休；每一天最多兩個區間。例行時段不保證臨時公休或假日異動。
- 時段未知的店不符合「只抽例行時段涵蓋用餐的店」；取消該條件後仍可參加抽選。
- Google 試算表與管理密語由擁有者自行在 Google 帳戶設定，名單文字不需包含密語。
- 餐點類別寫入 `RestaurantsFree.category`（G 欄），同格可有多種類別，葷素另外維護。舊分類的銜接與完整範例見 [分類維護](fill-restaurant-data.md)。
