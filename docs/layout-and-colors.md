# v6.9：餐點排列與固定配色

## 每排 4 個／8 個

「選餐點」頁右上角新增排列切換，預設每排 4 張類別卡片，可切換為每排 8 張。只改顯示密度，不影響類別順序、店家篩選、勾選或抽選機率。選擇記在目前瀏覽器，重新整理仍保留；瀏覽器不能儲存時仍可切換。

螢幕寬度大於 1100px 時提供 4／8 欄切換；641～1100px 使用 3 欄；640px 以下使用 2 欄。窄螢幕隱藏切換鈕，回到桌機寬度會恢復原本選擇。店家名單本身仍使用原來的響應式卡片排列。

## 顏色跟著餐點類別

分類入口、挑店家及店家名單共用 `src/catalog.js` 的分類與色群設定。顏色不再隨卡片位置輪流變換；搜尋、篩選與重新排列不會改變同一間店的顏色。

| 色群 | 類別 |
|---|---|
| 奶油黃・早餐速食 | 速食、早餐店、早午餐 |
| 杏桃色・飯食小吃 | 咖哩、小吃店、快餐便當、粥店、港式、台式、飯糰飯捲、鵝肉專賣、燒臘 |
| 薰衣草紫・麵食 | 拉麵、烏龍麵、牛肉麵 |
| 玫瑰粉・咖啡甜點 | 咖啡廳、輕食咖啡廳、冰店、甜點 |
| 霧藍・異國料理 | 韓式、義式、壽司、泰式、日式定食 |
| 陶土色・牛排鍋物 | 牛排、鍋物 |
| 鼠尾草綠・蔬食 | 素食 |

「不限」保留深綠色，「尚未分類」使用中性灰。同店跨色群時，卡片圖示區呈現分色背景，並列出所有類別標籤；同色群的多個類別仍只顯示一種背景色。色群及圖示的選擇不受儲存格內類別排列順序影響。

入口與店家名單有可展開的「顏色代表餐點類別」說明。色群方便辨認餐點，並非評分或推薦排名，也不會代替葷素欄位的判定。

試算表沿用原本 `category` 欄位，不用新增顏色欄、不用重新匯入店家。未辨認的分類仍會標示待確認，不替店家猜分類。

## 分數形容詞在哪裡？

此功能已存在，本次確認以下位置正常：

1. 「店家名單 → 點店家 → 我吃過，讓我說」：Google 登入後，拉動滑桿或直接填分數，旁邊的形容詞即時更新。
2. 同一個表單的「看完整嘴砲分級表」：列出全部 12 個區間。
3. 已送出的每則評論卡片：數字下方顯示對應形容詞，未登入訪客也看得到。

例如 -100 分「廚餘桶都申請退貨」、0 分「狗幹難吃」、100 分「頂上人間」、200 分「好吃到想把戶籍遷過來」。形容詞對應單則餐點評分，不是店家類別或轉盤抽選結果；送出確認視窗目前顯示數字分數。

## 更新部署

下載最新版 `Lunch-Club-Apps-Script.zip`，完整替換 ZIP 內 **Code.gs、Index.html**，到原部署「管理部署 → 編輯 → 新版本 → 部署」。重新開啟網站，在使用說明確認 **版本 6.9.0**。

Google 登入屬性、管理密語、試算表及既有評論全部保留；此版沒有變更登入機制或試算表格式。
